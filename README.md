# Skillify Landing Page

This is responsive, multi-page landing page for Skillify, an online education platform.

## Description

This project was built as part of Udacity's front-end web development nanodegree program. It demonstrates semantic HTML, custom CSS, responsive design with CSS Grid and Flexbox, and a clean component-based layout.

The site includes:

- A custom navbar and footer used across all pages
- A hero section with a call-to-action
- Info cards, about content, and program cards on the home page
- A contact page with office locations and a working form structure
- Responsive layouts for desktop, tablet, and mobile devices

## Technologies

- HTML5
- CSS3
- Google Fonts (Valley Sans)
- No external frameworks

## How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser, or run a local server from the project root:

   ```bash
   npx live-server
   ```

3. Visit the URL printed in the terminal for the home page and add `pages/contact.html` to the path for the contact page.
